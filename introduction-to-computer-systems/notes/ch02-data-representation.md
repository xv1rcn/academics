## 2.1 数制和编码基础

<a id="sec2-1-1"></a>
### 2.1.1 信息的二进制编码 ★★

**📌 考点概括** — 考"为什么用二进制"和bit/Byte基本概念，填空或判断题。

**📖 详细讲解**

计算机底层采用二进制，原因有三：(1)物理实现简单（高低电平对应0/1，抗干扰强）；(2)运算规则统一（布尔代数可直接用门电路实现）；(3)存储与传输可靠（两个状态间距大，信号衰减后仍能正确区分）。

基本单位：
- **bit（比特/位）**：最小信息单位，取值0或1
- **Byte（字节）**：1 Byte = 8 bit，存储寻址的基本单位
- **字（Word）**：CPU一次处理的数据宽度，常见16/32/64位

n个bit可表示 $2^n$ 种不同状态；8bit可表示256种状态，无符号范围0~255，补码范围−128~127。

**🔍 举例推演** — 4个bit可表示 $2^4=16$ 种状态，对应4位无符号整数0~15，或4位补码−8~7。

**✏️ 真题训练**

1. （填空）计算机内部所有信息（指令和数据）均以 \_\_\_\_\_\_ 形式存储和处理。
2. （判断）计算机采用二进制的主要原因是为了节省存储空间。（ ）

**答案与解析**
1. 二进制（0/1编码）。2. 错误。主因是物理实现简单可靠、抗干扰能力强。

<a id="sec2-1-2"></a>
### 2.1.2 进位计数制 ★★★

**📌 考点概括** — 二进制/八进制/十六进制/十进制互换是整章基础，不会换算则后续全部无法计算。

**📖 详细讲解**

任意 $R$ 进制数按权展开：$(a_n\dots a_1a_0.a_{-1}\dots a_{-m})_R = \sum_{i=-m}^{n} a_i \times R^i$

| 方向 | 整数部分 | 小数部分 |
|------|---------|---------|
| R进制→十进制 | 按权展开求和 | 按权展开求和 |
| 十进制→R进制 | **除R取余，倒序排列** | **乘R取整，正序排列** |
| 二进制↔八进制 | 从低位起3位一组 | 从高位起3位一组 |
| 二进制↔十六进制 | 从低位起4位一组 | 从高位起4位一组 |

> 分组法本质：$8=2^3$, $16=2^4$，每3/4位二进制恰好对应一位八/十六进制。

**🔍 举例推演**

**【例1】** $157.375_{10}$ 转二进制。整数157除2取余：157÷2=78余1, 78÷2=39余0, 39÷2=19余1, 19÷2=9余1, 9÷2=4余1, 4÷2=2余0, 2÷2=1余0, 1÷2=0余1 → 倒排10011101₂。小数0.375乘2取整：0.375×2=0.75取0, 0.75×2=1.5取1, 0.5×2=1.0取1 → 正排.011₂。结果：10011101.011₂。

**【例2】** 二进制1101 1010 1110.1011₂转十六进制。4位一组：`1101 D`, `1010 A`, `1110 E`, `.1011 B` → 0xDAE.B。

**【例3】** 0x3F.A → 十进制：$3×16 + 15×1 + 10×1/16 = 48 + 15 + 0.625 = 63.625_{10}$。

**✏️ 真题训练**

1. （填空）十进制数45的二进制为\_\_\_，十六进制为\_\_\_。
2. （选择）0x1A.8 = ( )₁₀ — A. 26.5  B. 26.8  C. 26.125  D. 26.625
3. （计算）将10110.101₂分别转换为十进制和十六进制。

**答案与解析**
1. 101101₂, 0x2D（45÷2: 110110倒排；0010 1101 → 2D）。2. A（16+10+0.5=26.5）。3. 十进制22.625；十六进制0x16.A。

### 2.1.3 定点与浮点表示 ★★

**📌 考点概括** — 定点与浮点的基本思想、区别和适用场景，概念选择题。

**📖 详细讲解**

|  | 定点数 | 浮点数 |
|---|--------|--------|
| 基本思想 | 小数点位置**固定** | 小数点位置**可变**（由阶码决定） |
| 表示形式 | 纯整数或纯小数 | $N = M \times R^E$（尾数×基数^阶码） |
| 运算难度 | 简单（当整数运算） | 复杂（需对阶→运算→规格化→舍入） |
| 表示范围 | 窄 | 宽（阶码使小数点可大幅移动） |
| 精度 | 均匀（相邻两数间距恒定） | 不均匀（靠近0精度高，远离0精度低） |
| 典型用途 | 整数运算、定点DSP | 科学计算、图形学 |

**关键直觉**：32位定点整数范围约$\pm 2\times10^9$，32位浮点数范围可达$\pm 3.4\times10^{38}$——阶码等效于指数缩放。但浮点只有约$2^{32}$个不同值，稀疏分布在大范围内。

**✏️ 真题训练**

1. （填空）浮点数N=M×R^E中，M称\_\_\_，E称\_\_\_。
2. （判断）定点数适合表示范围跨度极大的科学计算数据。（ ）

**答案与解析**
1. 尾数、阶码。2. 错误，应使用浮点数。

<a id="sec2-1-4"></a>
### 2.1.4 定点数的编码表示 ★★★

**📌 考点概括** — 原码/反码/补码/移码的定义、计算、表示范围，全章最核心考点。

**📖 详细讲解**

设n位编码（含符号位，最左为符号位：0正1负）。

| 编码 | 正数规则 | 负数规则 | 0的表示 |
|------|---------|---------|---------|
| **原码** | 符号0 + 绝对值 | 符号1 + 绝对值 | ±0（00..0和10..0） |
| **反码** | 符号0 + 绝对值 | 符号1 + 绝对值逐位取反 | ±0（00..0和11..1） |
| **补码** | 符号0 + 绝对值 | 反码末位+1 | 仅00..0 |
| **移码** | 真值+ $2^{n-1}$ | 同左 | 10..0 |

**补码快捷求法**：从右往左扫描，遇到第一个1之前的所有0不变，第一个1不变，其左侧所有位取反。

**补码的数学本质——同余**：模为$2^n$，负数$x$的补码$=2^n-|x|$。因此$[x]_补+[y]_补 \equiv x+y \pmod{2^n}$，加减统一为加法，无需额外减法电路。

**n位表示范围**：原码/反码 $[-(2^{n-1}-1), 2^{n-1}-1]$, 共$2^n-1$个（±0）。补码/移码 $[-2^{n-1}, 2^{n-1}-1]$, 共$2^n$个（0唯一）。补码比原码多一个负数$-2^{n-1}$。

**补码与移码关系**：对同一真值，补码符号位取反即得移码。

**🔍 举例推演**

**【例1】** 8位补码求真值−46。绝对值46=00101110₂，快捷法：右起bit1=1为第一个1，左侧全取反→11010010₂。验证：−128+64+16+2=−46✓。

**【例2】** 8位补码10010110₂求真值。符号1→负数。取反+1：01101001+1=01101010=106→真值−106。或用负权求和：−128+16+4+2=−106。

**【例3】** 8位移码求真值+5。偏置=128，移码=5+128=133=10000101₂。

**✏️ 真题训练**

1. （填空）8位补码最小整数\_\_\_，最大整数\_\_\_。
2. （计算）4位编码1011分别按原码、反码、补码解释，求十进制真值。
3. （判断）8位反码中+0和−0有不同的编码。（ ）
4. （选择）对真值−5，其8位补码与移码的关系是（ ）— A.相同 B.相反数 C.符号位取反即得 D.无关

**答案与解析**
1. −128、127。2. 原码−3(符号1,绝对值011)，反码−4(取反得100=4)，补码−5(取反+1得0101=5)。3. 正确(+0=00000000, −0=11111111)。4. C。

## 2.2 整数的表示

<a id="sec2-2-1"></a>
### 2.2.1 无符号整数和带符号整数的表示 ★★★

**📌 考点概括** — 范围公式、补码同余原理、"位不变解释可变"的核心思想。

**📖 详细讲解**

对n位位模式$\vec{b}=b_{n-1}b_{n-2}\dots b_0$：
- **无符号**：$U(\vec{b})=\sum_{i=0}^{n-1} b_i \times 2^i$
- **补码（有符号）**：$T(\vec{b})=-b_{n-1}\times 2^{n-1}+\sum_{i=0}^{n-2} b_i \times 2^i$（最高位**负权**）

| 类型 | 范围 | 公式 |
|------|------|------|
| 无符号 | $0 \sim 2^n-1$ | UMin=0, UMax=$2^n-1$ |
| 补码 | $-2^{n-1} \sim 2^{n-1}-1$ | TMin=$-2^{n-1}$, TMax=$2^{n-1}-1$ |

**TMin的特殊性**：$-2^{n-1}$的相反数求取反+1后仍是自身（因为$+2^{n-1}$超出补码范围，模运算绕回），这是整数运算经典陷阱。

**🔍 举例推演**

**【例1】** 16位：无符号最大65535，补码最大32767，补码最小−32768。

**【例2】** 位模式10000001₂：无符号=129，补码=−127。同一字节，解释不同则真值不同。这是C语言类型转换的底层原理。

**【例3】** TMin(−128)取反+1：10000000→取反01111111→+1=10000000，仍为−128。

**✏️ 真题训练**

1. （填空）16位无符号最大\_\_\_；16位补码最小\_\_\_。
2. （计算）位模式11000101分别按无符号和补码求真值。
3. （判断）n位补码的TMin等于其相反数。（ ）

**答案与解析**
1. 65535、−32768。2. 无符号197(128+64+4+1)，补码−59(取反+1得59)。3. 错误（相反数超出范围，仍是自身）。

<a id="sec2-2-2"></a>
### 2.2.2 C语言中的整数及其相互转换 ★★★

**📌 考点概括** — signed/unsigned转换规则、混合运算隐式提升、经典陷阱（`-1<0U`为假）。

**📖 详细讲解**

**强制类型转换规则：位模式不变，仅改变解释方式。**

$$
T2U_n(x)=\begin{cases}x & x\ge0\\x+2^n & x<0\end{cases}
\qquad
U2T_n(u)=\begin{cases}u & u\le2^{n-1}-1\\u-2^n & u\ge2^{n-1}\end{cases}
$$

**混合运算隐式提升**：signed与unsigned混用时，signed**隐式提升为unsigned**。经典陷阱：
```c
-1 < 0U  // -1提升为unsigned→4294967295 < 0 → 假！
```

**宽度扩展**（赋值给更宽变量）：无符号→零扩展（高位补0）；补码→符号扩展（高位补符号位）。

**C常见整数类型宽度**（LP64）：`char` 8bit, `short` 16bit, `int` 32bit, `long` 64bit。

**🔍 举例推演**

**【例1】** 8位补码−46(11010010₂)→无符号=128+64+16+2=210。公式验证：−46+256=210✓。

**【例2】** 8位无符号200(11001000₂)→补码=−128+64+8=−56。公式验证：200−256=−56✓。

**【例3】** `short s=-1`(0xFFFF)→`int i=s`→0xFFFFFFFF(符号扩展，真值=−1)。`unsigned ui=s`→先符号扩展得0xFFFFFFFF→无符号=4294967295。

**✏️ 真题训练**

1. （判断）`-1 < 1U`值为真。（ ）
2. （选择）`unsigned u=10; int i=-42; printf("%d\n",i+i); printf("%u\n",i+u);`输出（ ）— A.−84和−32 B.−84和4294967264 C.4294967212和−32 D.−84和32
3. （计算）`((int)((unsigned)(-1)>>1))`的值（假设32位int）。

**答案与解析**
1. 错误。−1提升为unsigned→4294967295>1，故表达式为假。2. B。行1两个int相加=−84；行2 i提升为unsigned(−42→4294967254)+10=4294967264。3. 2147483647。`(unsigned)(-1)`=0xFFFFFFFF，逻辑右移1位→0x7FFFFFFF→int=2147483647。

## 2.3 浮点数的表示（深度融合 2.3.1~2.3.4）

<a id="sec2-3-1"></a>
### IEEE 754浮点数标准 ★★★

**📌 考点概括** — IEEE 754位布局、规格化/非规格化/特殊值的真值计算。每次必考计算题。

**📖 详细讲解**

#### 一、浮点数基本形式

$N=M\times R^E$。规格化：尾数绝对值$[1,R)$，确保表示唯一。**隐含前导1**：基数为2时规格化尾数整数部分恒为1，不存储——23位尾数实际表达24位精度。

#### 二、IEEE 754单精度（32bit）位布局

```
  31 30       23 22                    0
 ┌───┬──────────┬───────────────────────┐
 │ S │  E (8)   │      M (23)           │
 └───┴──────────┴───────────────────────┘
 符号  阶码(移码)    尾数(小数部分,隐含前导1)
```

双精度（64bit）：S(1)+E(11,偏置1023)+M(52)。

#### 三、真值计算公式

| 阶码E | 尾数M | 真值 |
|-------|-------|------|
| E=0, M=0 | 全0 | **±0**（由S决定符号） |
| E=0, M≠0 | 非全0 | **非规格化**：$(-1)^S \times 0.M \times 2^{-126}$ |
| 1≤E≤254 | 任意 | **规格化**：$(-1)^S \times 1.M \times 2^{E-127}$ |
| E=255, M=0 | 全0 | **±∞** |
| E=255, M≠0 | 非全0 | **NaN** |

**非规格化数的意义**：0与最小规格化数($\approx1.18\times10^{-38}$)之间存在巨大间隙。非规格化数$0.M\times2^{-126}$填平此间隙，实现"渐进下溢"。

#### 四、C语言浮点类型

| C类型 | IEEE 754 | 宽度 | 有效数字(十进制) |
|-------|---------|:---:|:---:|
| `float` | 单精度 | 32bit | ~7位 |
| `double` | 双精度 | 64bit | ~15-16位 |
| `long double` | 扩展双精度(80bit) | ≥64bit | 取决于实现 |

> 浮点运算指令见第3章[算术运算指令](./ch03-machine-level.md#sec3-3-2)。

**🔍 举例推演**

**【例1】−10.625 → IEEE 754单精度**

```
(1) S=1 (负数)
(2) 10.625二进制: 10÷2取余→1010₂; 0.625×2=1.25→1→0.5×2=1.0→1→.101₂
    合并: 1010.101₂
(3) 规格化: 1.010101×2³ → M=01010100000000000000000 (隐含1去掉,补0至23位)
(4) E=3+127=130=10000010₂
(5) 拼接: 1 10000010 01010100000000000000000 → 0xC1540000
```

**【例2】0x41C80000 → 真值**

```
二进制: 0 10000011 10010000000000000000000
S=0, E=131, M=1001... = 0.5+0.0625=0.5625
规格化数: (−1)⁰×(1.5625)×2^(131−127)=1.5625×16=25.0
```

**【例3】特殊值速查**

```
+0=0x00000000     −0=0x80000000
+∞=0x7F800000     −∞=0xFF800000
NaN例=0x7FC00000
最小正非规格化=0x00000001 (≈1.40×10⁻⁴⁵)
最大规格化=0x7F7FFFFF (≈3.40×10³⁸)
1.0=0x3F800000    −1.0=0xBF800000
```

**✏️ 真题训练**

1. （计算）将−6.125转换为IEEE 754单精度二进制表示，写出详细步骤。
2. （计算）某IEEE 754单精度值0xC0A00000，求十进制真值。
3. （选择）以下哪个代表NaN？— A. 0x7F800000 B. 0xFF800000 C. 0x7F800001 D. 0x00000000
4. （填空）单精度最小规格化正数≈\_\_\_，最小正非规格化数≈\_\_\_。

**答案与解析**
1. S=1; 6.125=110.001₂→规格化1.10001×2², M=100010...0, E=2+127=129=10000001₂→0xC0C40000。2. S=1, E=129→指数2, M=1.01₂=1.25, 真值=−1.25×4=−5.0。3. C（E=255且M≠0）。4. $1.18\times10^{-38}, 1.40\times10^{-45}$。

## 2.4 十进制数的表示

<a id="sec2-4-1"></a>
### ASCII码与BCD码 ★

**📌 考点概括** — ASCII关键码值记忆和8421 BCD编码规则，1~2分小题。

**📖 详细讲解**

**ASCII关键规律**（必记）：

| 字符 | 十六进制 | 规律 |
|------|:---:|------|
| `'0'` | 0x30 | 数字字符 = 0x30 + 数字值 |
| `'A'` | 0x41 | 大写从0x41起连续排列 |
| `'a'` | 0x61 | 小写从0x61起连续排列 |

> 大小写差0x20：`'A'`(0100 0001) vs `'a'`(0110 0001)——bit5为0是大写、为1是小写。转换：`小写=大写|0x20`，`大写=小写&~0x20`。

**8421 BCD码**：4位二进制表示1位十进制数字（0~9），每位权值8-4-2-1。1010~1111(10~15)为非法码。

```
十进制 0→0000, 1→0001, ..., 9→1001
十进制 25 → 0010 0101 (BCD)
十进制 593 → 0101 1001 0011 (BCD) = 0x593
```

**🔍 举例推演** — ASCII字符串"AB"存储为0x41 0x42。'9'=0x30+9=0x39。十进制47的BCD码=0100 0111。

**✏️ 真题训练**

1. （填空）ASCII中'9'=0x\_\_\_，'b'=0x\_\_\_。
2. （选择）十进制47的8421 BCD码是（ ）— A. 0100 0111  B. 0010 1111  C. 0100 0111(BCD)  D. 0111 0100(BCD)
3. （判断）BCD码每1位十进制数字由8个二进制位表示。（ ）

**答案与解析**
1. 0x39, 0x62。2. C（4→0100, 7→0111）。3. 错误（4位，非8位）。

## 2.6 数据的宽度和存储

<a id="sec2-6-1"></a>
### 2.6.1 数据的宽度和单位 ★★

**📌 考点概括** — 存储单位换算（bit/Byte/KB/MB/GB）、字长概念，填空题。

**📖 详细讲解**

| 单位 | 字节数 | 精确值 |
|------|:---:|------|
| 1 KB | $2^{10}$ | 1,024 Byte |
| 1 MB | $2^{20}$ | 1,048,576 Byte |
| 1 GB | $2^{30}$ | 1,073,741,824 Byte |

> 硬盘厂商常用十进制（1KB=1000Byte），与OS显示的二进制值有差异。

**字长**：CPU一次处理的数据宽度，决定寄存器宽度和地址空间大小。32位机器虚拟地址空间=$2^{32}$ Byte = 4 GB。

**✏️ 真题训练**

1. （填空）4 GB = \_\_\_ MB = \_\_\_ Byte。
2. （填空）32位机器虚拟地址空间最大为\_\_\_ GB。

**答案与解析**
1. 4096, $4\times2^{30}=4{,}294{,}967{,}296$。2. 4 GB。

### 2.6.2 数据的存储和排列顺序 ★★

**📌 考点概括** — 大端/小端字节序的判断，union/指针判断端序方法。选择/填空/读程序题。

**📖 详细讲解**

对于多字节数据`int x=0x12345678`（地址0x100起）：

```
大端(Big-Endian): 高字节存低地址 (符合人类书写习惯)
  地址: 0x100  0x101  0x102  0x103
  内容: 0x12   0x34   0x56   0x78

小端(Little-Endian): 低字节存低地址 (x86/x64, 多数ARM)
  地址: 0x100  0x101  0x102  0x103
  内容: 0x78   0x56   0x34   0x12
```

**记忆口诀**：大端"高对低"（高字节低地址）；小端"低对低"（低字节低地址）。IA-32/x86 使用小端序，在汇编层面直接体现（参见[第3章IA-32数据类型](./ch03-machine-level.md#sec3-2-1)）。

**判断端序的方法**：

```c
// 方法1: union
union { int i; char c[4]; } u;
u.i = 0x12345678;
// 小端: u.c[0]==0x78; 大端: u.c[0]==0x12

// 方法2: 指针强制转换
int x = 0x12345678;
char *p = (char*)&x;
// 小端: *p==0x78; 大端: *p==0x12
```

> 网络字节序 = 大端序。x86发送网络数据需用`htonl`/`htons`转换。

**🔍 举例推演**

**【例】** 小端机器上`int a=0x01020304`存于0x2000：地址0x2000→0x04, 0x2001→0x03, 0x2002→0x02, 0x2003→0x01。`short *sp=(short*)&a;`读取地址0x2000处16位：小端=0x0304。

**✏️ 真题训练**

1. （填空）小端机器上`int x=0xAABBCCDD`存于0x1000，则0x1000处字节=0x\_\_，0x1001=0x\_\_。
2. （选择）正确说法是（ ）— A.大端下低字节存高地址 B.x86是大端 C.网络字节序是小端 D.union不能判断端序
3. （填空）小端机器上：`unsigned int a=0x12345678; unsigned char *p=(unsigned char*)&a; printf("%02X\n",p[2]);`输出\_\_\_。

**答案与解析**
1. 0xDD, 0xCC。2. A。3. 34（p[0]=0x78, p[1]=0x56, p[2]=0x34, p[3]=0x12）。

## 2.7 数据的基本运算

<a id="sec2-7-1"></a>
### 2.7.1 按位运算和逻辑运算 ★★

**📌 考点概括** — `&`/`&&`、`|`/`||`、`~`/`!`的区别（操作对象、返回值、短路特性）。

**📖 详细讲解**

| 特性 | 按位(`&` `|` `~` `^`) | 逻辑(`&&` `||` `!`) |
|------|-------------------|---------------------|
| 操作对象 | 每个bit | 表达式真值(0假/非0真) |
| 返回值 | 同类型整数 | 仅0或1 |
| 短路求值 | 无 | **有** |

**短路求值陷阱**：

```c
int a=0;
if (a!=0 && ++a>0) ;  // a!=0假→短路, ++a不执行, a仍为0

int b=0;
if (b==0 || ++b>0) ;  // b==0真→短路, ++b不执行, b仍为0
```

**位操作常用技巧**：第k位置1→`x|(1<<k)`；第k位清零→`x&~(1<<k)`；测试第k位→`(x>>k)&1`；取最低位1→`x&-x`。

**🔍 举例推演**

x=0x5A(01011010₂), y=0x3C(00111100₂)：
`x&y`=00011000=0x18; `x|y`=01111110=0x7E; `x^y`=01100110=0x66; `~x`=10100101=0xA5。

短路：`int x=5,y=0; if(x>3||++y);`→`x>3`真→`++y`不执行→y=0。

**✏️ 真题训练**

1. （填空）`0x3C & 0x0F` = 0x\_\_\_。
2. （选择）执行后`int a=1,b=0; if(a--||++b);` a,b值（ ）— A.0,0 B.1,1 C.0,1 D.1,0
3. （判断）`0x55 && 0xAA`结果为0。（ ）

**答案与解析**
1. 0x0C（00111100 & 00001111 = 00001100）。2. A（`a--`先用1(真)→短路→a减为0, b=0）。3. 错误（逻辑与，均非零→1）。

<a id="sec2-7-2"></a>
### 2.7.2 左移运算和右移运算 ★★

**📌 考点概括** — 逻辑移位vs算术移位补位规则、移位与乘除$2^n$关系、算术右移vs C除法向零舍入的区别。

**📖 详细讲解**

**左移(<<)**：逻辑/算术相同，高位丢弃，低位补0。每左移1位=×2。

**右移(>>)**：

| 类型 | 高位补 | 适用 | 数学意义 |
|------|--------|------|---------|
| 逻辑右移 | 补0 | 无符号数 | 无符号÷$2^n$ |
| 算术右移 | 补符号位 | 补码 | 有符号÷$2^n$（向负无穷舍入） |

**致命区别——算术右移 vs C整数除法**：
```
C语言: −5/2 = −2  (向零舍入)
算术右移: −5>>1 (补码11111011→11111101=−3)  (向负无穷舍入)
```
因此编译器不能简单用`SAR`替代有符号除法——负数需加偏置修正。

**🔍 举例推演**

**【例1】** `unsigned char x=0xA5(10100101₂)`：`x<<1`→01001010=0x4A；`x>>1`(逻辑)→01010010=0x52。

**【例2】** `signed char y=−20(11101100₂)`：`y<<1`→11011000=−40(×2)；`y>>2`(算术)→11111011=−5(÷4)✓。

**【例3】** 算术右移舍入：−5(11111011)>>1=11111101=−3；而−5/2=−2。不等！

**✏️ 真题训练**

1. （填空）8位无符号0xB4逻辑右移2位=0x\_\_\_。
2. （计算）8位补码−26算术右移2位的过程和十进制结果。
3. （判断）C语言中`(−5)>>1`和`(−5)/2`结果相同。（ ）

**答案与解析**
1. 0x2D（10110100>>2(逻辑)=00101101=0x2D）。2. −26补码=11100110→右移2位→11111001=−128+64+32+16+8+1=−7（−26/4=−6.5→向负无穷=−7）。3. 错误（原因见上）。

<a id="sec2-7-3"></a>
### 2.7.3 位扩展运算和位截断运算 ★★

**📌 考点概括** — 零扩展/符号扩展规则、截断后值变化（模运算绕回）。

**📖 详细讲解**

**位扩展（窄→宽）**：
- 无符号→更宽无符号：**零扩展**（高位补0），真值不变
- 补码→更宽补码：**符号扩展**（高位补符号位），真值不变
- 补码→更宽无符号：先符号扩展，再按无符号解释

**位截断（宽→窄）**：丢弃高位，保留低k位。截断后值=原值 mod $2^k$（k为截断后位数）。高位非零时数值可能剧烈变化。

**🔍 举例推演**

**【例1】** 8位补码−46(11010010₂)→16位补码：高位全补1→1111111111010010=−46✓。

**【例2】** 8位无符号210(11010010₂)→16位无符号：高位补0→0000000011010010=210✓。

**【例3】** 32位int=0x1234ABCD截断为16位→0xABCD=43981。32位int=2000000000(0x77359400)截断8位→0x00=0（数据完全丢失）。

**【例4】** 32位int=−1(0xFFFFFFFF)截断16位→0xFFFF=−1（高位全1，截断后仍为−1）。

**✏️ 真题训练**

1. （填空）16位补码−300扩展为32位补码，高16位填0x\_\_\_。
2. （计算）32位无符号0x1234ABCD截断16位的十进制值。
3. （判断）补码符号扩展为更宽补码后，真值一定不变。（ ）

**答案与解析**
1. 0xFFFF（负数→符号1→全填1）。2. 0xABCD=43981。3. 正确（补码符号扩展的重要数学性质）。

<a id="sec2-7-4"></a>
### 2.7.4 整数加减运算 ★★★

**📌 考点概括** — 补码加减统一性、溢出判断$C_n\oplus C_{n-1}$、CF/ZF/SF/OF标志位。计算+判断题标配。

**📖 详细讲解**

**补码加减统一**：无论有无符号，同一套加法器完成。$A-B=A+(-B)_{补}$，模$2^n$自动处理进位/借位。

**溢出判断——双高位进位法**：
- $C_n$：最高位(符号位)向更高位的进位
- $C_{n-1}$：次高位向最高位的进位
- 无符号溢出：$CF=C_n$（=1则溢出）
- **有符号溢出**：$OF=C_n \oplus C_{n-1}$（异或，=1则溢出）

**溢出只发生在**：正+正=负、负+负=正、正−负=负、负−正=正。正+负永不溢出。

**标志位**：

| 标志 | 含义 | 用于 |
|------|------|------|
| CF | 无符号溢出（进位/借位） | JA/JB（无符号跳转） |
| ZF | 结果为0 | JZ/JE |
| SF | 结果符号位 | JS/JNS |
| OF | 补码溢出 | JG/JL（有符号跳转） |

详见第3章[条件跳转](./ch03-machine-level.md#sec3-4-2)对标志位的综合运用。

**🔍 举例推演**

**【例1】** 8位补码90+80：

```
  0101 1010 (90)
+ 0101 0000 (80)
  ─────────
  1010 1010 (−86)
```
Cn-1=1(bit6→bit7进位), Cn=0(bit7无进位)。OF=1⊕0=1→溢出！正+正=负。

**【例2】** 8位补码−100+80：

```
  1001 1100 (−100)
+ 0101 0000 (80)
  ─────────
  1110 1100 (−20) ✓
```
Cn-1=1, Cn=1, OF=1⊕1=0→无溢出。

**【例3】** 8位补码−100+(−80)：

```
  1001 1100 (−100)
+ 1011 0000 (−80)
  ─────────
1 0100 1100 (进位丢弃, 低8位=+76)
```
Cn-1=0, Cn=1, OF=1⊕0=1→溢出！负+负=正。CF=1(无符号溢出)。

**✏️ 真题训练**

1. （计算）8位补码−110+(−60)，列出Cn/Cn-1/OF，判断有无溢出。
2. （填空）若Cn=0, Cn-1=1，则OF=\_\_\_，表示\_\_\_数溢出。
3. （选择）一定不会产生补码溢出的操作是（ ）— A.正+正 B.负+负 C.正+负 D.0+正
4. （判断）无符号加法溢出时CF标志必为1。（ ）

**答案与解析**
1. −110=10010010, −60=11000100。相加：
```
  1001 0010
+ 1100 0100
  ─────────
1 0101 0110 (低8位=86)
```
bit6→bit7: 0+0=0无进位→Cn-1=0; bit7: 1+1+0=0进1→Cn=1。OF=1⊕0=1→溢出（−170超出[−128,127]）。
2. 1，有符号。3. C（正+负=绝对值相减，永不溢出）。4. 正确（CF=Cn，溢出必为1）。

<a id="sec2-7-5"></a>
### 2.7.5 整数乘除运算 ★★ + 2.7.6 常量乘除优化 ★☆

**📌 考点概括** — 乘法结果宽度翻倍、除法向零舍入、除零/INT_MIN/(−1)溢出、编译器用移位+加减优化常量乘除。

**📖 详细讲解**

**整数乘法**：两个n位数相乘，乘积最多2n位。C语言取低n位→截断。x86中`IMUL`/`MUL`结果存EDX:EAX（64位）。

**整数除法向零舍入**：$7/2=3, -7/2=-3$（C语言标准）。

**两个极端溢出**：除零（未定义/异常）、`INT_MIN/(-1)`（32位：期望+2147483648超INT_MAX）。

**常量乘除的编译器优化**：

| 乘数 | 优化 | 说明 |
|:---:|------|------|
| ×3 | `(x<<1)+x` | 2x+x |
| ×5 | `(x<<2)+x` | 4x+x |
| ×9 | `(x<<3)+x` | 8x+x |
| ×10 | `(x<<3)+(x<<1)` | 8x+2x |
| ×17 | `(x<<4)+x` | 16x+x |

常量除法（除数为$2^k$）：无符号直接用逻辑右移；补码需加偏置修正——`(x<0 ? (x+(1<<k)-1) : x) >> k`，补偿向零vs向负无穷的舍入差异。

**🔍 举例推演**

**【例1】** 编译器优化×18→`(x<<4)+(x<<1)`（16x+2x）。

**【例2】** `int a=INT_MIN, b=-1; int c=a/b;`→溢出（结果+2³¹超出INT_MAX=2³¹−1）。

**【例3】** C除法vs算术右移：−7/4=−1(向零)，−7>>2=−2(向负无穷)。编译器修正：`(−7+3)>>2=(−4)>>2=−1`✓。

**✏️ 真题训练**

1. （填空）两个8位整数相乘，积最多需要\_\_\_位。
2. （选择）`5/2`和`−5/2`值分别是（ ）— A.3和−3 B.2和−3 C.2和−2 D.3和−2
3. （填空）编译器对`x*7`可优化为\_\_\_。

**答案与解析**
1. 16。2. C（向零舍入：2.5→2, −2.5→−2）。3. `(x<<3)-x`（8x−x=7x）或`(x<<2)+(x<<1)+x`。

<a id="sec2-7-7"></a>
### 2.7.7 浮点数运算（仅简单加减）★☆

**📌 考点概括** — 浮点加减四步流程（对阶→尾数加减→规格化→舍入）、大数吃小数。概念简答题。

**📖 详细讲解**

浮点加减四步：
1. **对阶**：小阶向大阶看齐（小数的尾数右移，阶码增加直至与大阶一致）
2. **尾数加减**：对齐后尾数相加减
3. **规格化**：结果尾数调整到$[1,2)$，同时修正阶码
4. **舍入**：超出有效位的尾数按IEEE 754规则舍入（默认向偶数舍入）

**大数吃小数**：当两个浮点数阶差≥尾数精度位数时，对阶时小数的尾数被完全移出变为0——小数被"吃"掉。

> 例(单精度23位尾数)：$1.0\times2^{25}+1.0\times2^0$。对阶时$1.0\times2^0$右移25位→0。结果=$1.0\times2^{25}$，小数被吃。

**四种舍入模式**：向偶数舍入（默认）、向零、向正无穷、向负无穷。

**🔍 举例推演**

**【例】** 单精度0.5+(−0.4375)：
```
0.5 = 1.0 × 2⁻¹ = 0.1₂ × 2⁰
−0.4375 = −(0.25+0.125+0.0625) = −0.0111₂ × 2⁰
①对阶: 同阶，无需对
②尾数加减: 0.1₂+(−0.0111₂)=0.0001₂
③规格化: 0.0001₂=1.0×2⁻⁴
④结果=1.0×2⁻⁴=0.0625
```

**✏️ 真题训练**

1. （填空）浮点加减第一步是\_\_\_，原则是\_\_\_。
2. （判断）大数吃小数是因为对阶时小数尾数右移导致有效位丢失。（ ）
3. （简答）简述浮点加减四步，说明为何小阶向大阶看齐而非相反。

**答案与解析**
1. 对阶；小阶向大阶看齐。2. 正确。3. 四步：对阶→尾数加减→规格化→舍入。理由：大阶向小阶看齐会丢失大数高位有效数字，损失更大；小阶向大阶看齐仅丢失小数低位。

### 二、IEEE 754单精度速查

```
位布局: [S(1)|E(8)|M(23)], 偏置=127
真值:
  E=0,M=0    → ±0
  E=0,M≠0    → (−1)^S×0.M×2^(−126)    (非规格化)
  1≤E≤254    → (−1)^S×1.M×2^(E−127)   (规格化)
  E=255,M=0  → ±∞
  E=255,M≠0  → NaN
```

| 特殊值 | 十六进制 |
|--------|----------|
| +0 | 0x00000000 |
| −0 | 0x80000000 |
| +∞ | 0x7F800000 |
| −∞ | 0xFF800000 |
| 1.0 | 0x3F800000 |
| −1.0 | 0xBF800000 |
| 最小非规格化正数 | 0x00000001 (~1.40×10⁻⁴⁵) |
| 最大规格化 | 0x7F7FFFFF (~3.40×10³⁸) |

### 五、经典易错陷阱

| 陷阱 | 真相 |
|------|------|
