\question{
    设计一个 Java 程序，完成：有一群海盗（不多于 $20$ 人）在船上比拼酒量。过程如下：打开一瓶酒，所有在场的人平分喝下，有几个人倒下了；再打开一瓶酒平分，又有倒下的；再次重复，直到开了第 $4$ 瓶酒，坐着的已经所剩无几，海盗船长也在其中。当第 $4$ 瓶酒平分喝下后，大家都倒下了。
