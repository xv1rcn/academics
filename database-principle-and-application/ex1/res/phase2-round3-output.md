## 七、数据安全与防护策略

### 7.1 应用层数据安全防护

**SQL注入三级防护：**
1. 代码层：MyBatis #{} 预编译 + 动态SQL字段白名单
2. 网关层：WAF SQL注入特征规则库实时拦截（准确率>=99.9%）
3. 数据库层：最小权限原则，各微服务独立账号

**XSS/CSRF防护：** HTML转义过滤器 + CSP策略 + Token校验

**敏感数据全生命周期保护：**
- 存储：身份证/手机号AES加密，密码BCrypt哈希
- 传输：全链路HTTPS/TLS 1.3
- 展示：分级脱敏
- 审计：全量访问日志

### 7.2 数据备份与容灾策略

三级备份体系：实时主备 + 定时备份 + 异地归档

| 数据类型 | 备份方式 | 周期 | 保留 |
|---------|---------|------|------|
| MySQL核心数据 | 主从半同步 | 实时 | 永久 |
| MySQL全量 | XtraBackup | 每日 | 30天 |
| MySQL增量 | 二进制日志 | 每小时 | 30天 |
| Redis | RDB+AOF | 实时+5分钟 | 7天 |
| 文件附件 | 全量 | 每周 | 90天 |
| 归档数据 | 冷备 | 每月 | 3年 |

灾备指标：主备切换<5分钟，RPO<15分钟，RTO<1小时
