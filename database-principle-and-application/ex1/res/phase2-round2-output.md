## 四、系统部署方案

### 4.1 部署设计原则
高可用、高性能、安全合规、弹性扩展。所有核心节点均采用集群/主备模式，无单点故障。

### 4.2 生产环境服务器配置（共约40个节点）

| 部署层级 | 节点类型 | 数量 | 配置 |
|---------|---------|------|------|
| 接入安全层 | 负载均衡 | 2（主备） | 8核/16G/200G SSD |
| 接入安全层 | WAF | 2（主备） | 8核/16G/200G SSD |
| 应用服务层 | 核心微服务节点 | 6（集群） | 16核/32G/500G SSD |
| 应用服务层 | 非核心微服务节点 | 4（集群） | 8核/16G/300G SSD |
| 中间件层 | Redis缓存集群 | 6（3主3从） | 8核/16G/500G SSD |
| 中间件层 | RocketMQ | 3（集群） | 8核/16G/1T SSD |
| 中间件层 | Nacos+XXL-Job | 3（集群） | 4核/8G/200G SSD |
| 数据存储层 | MySQL主库 | 2（主备） | 32核/64G/2T SSD |
| 数据存储层 | MySQL从库 | 2（只读） | 32核/64G/2T SSD |
| 数据存储层 | ClickHouse | 3（集群） | 16核/32G/4T SSD |
| 数据存储层 | Elasticsearch | 3（集群） | 8核/16G/1T SSD |
| 数据存储层 | MinIO | 3（集群） | 8核/16G/4T SAS |
| 运维监控层 | 监控日志节点 | 2（主备） | 8核/16G/2T SSD |

### 4.3 网络拓扑（5个安全区域）
1. 外网接入区：防火墙+WAF+负载均衡
2. DMZ隔离区：门户网关+认证服务+API网关
3. 业务服务区：全部微服务应用节点
4. 数据存储区：最高安全等级，仅允许业务区指定IP访问
5. 运维管理区：堡垒机+监控平台+日志审计

## 五、核心数据字典

命名规范：业务表`edu_`前缀，系统表`sys_`前缀。所有业务表含通用字段。

### 5.2 核心实体数据字典（共7张表）

1. **sys_department** — 院系信息表（10字段）
2. **sys_major** — 专业信息表（10字段，外键→sys_department）
3. **edu_student** — 学生信息表（14字段，外键→sys_department, sys_major）
4. **edu_teacher** — 教师信息表（12字段，外键→sys_department）
5. **edu_course** — 课程信息表（14字段，外键→sys_department）
6. **edu_enrollment** — 选课记录表（12字段，外键→edu_student, edu_course, edu_teacher）
7. **edu_score** — 成绩信息表（15字段，外键→edu_enrollment, edu_student, edu_course）
